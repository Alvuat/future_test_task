# Forme

Сервис для создания формы отклика, публикации ссылки и просмотра ответов.

## Запуск

Требуется Node.js 20 или новее. В корне проекта выполните:

```sh
npm install
npm start
```

Откройте [http://localhost:3000](http://localhost:3000), чтобы увидеть список форм и статусы. Админка с конструктором, публикацией и откликами доступна по адресу [http://localhost:3000/admin](http://localhost:3000/admin). Порт можно изменить переменной окружения `PORT`. Команда `npm start` собирает интерфейс и запускает встроенный HTTP-сервер.

Админка открывается без авторизации. Сервер отдаёт клиентское приложение на `/admin`, а также на опубликованных ссылках `/f/<id>` и странице подтверждения `/f/<id>/sent`.

## Возможности

- Создание форм с короткими, email, ссылочными и развёрнутыми полями.
- Публикация и снятие публикации формы с уникальным адресом `/f/<id>`.
- Отправка студенческих откликов и просмотр каждого ответа в админке.
- Локальное хранение форм и ответов в `data/store.json` без отдельной базы данных.
